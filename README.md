# Fund Name Vote

A lightweight bilingual voting page for choosing a Chinese-English fund name.

## Local

```bash
npm start
```

Open:

```text
http://127.0.0.1:4173/names.html
```

## Render

Deploy this repository as a Render Blueprint. Render reads `render.yaml`, starts the Node server, and stores voting data on a persistent disk at `/var/data/names.json`.
